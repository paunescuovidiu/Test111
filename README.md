# Nova Arhistudio

A contemporary architecture and interior design website, with responsive layouts, a filterable portfolio, project detail views, and downloadable enquiry briefs.

## Getting started

Clone the repository:

```sh
git clone https://github.com/paunescuovidiu/Test111.git
cd Test111/nova-arhistudio
node serve.mjs
```

Open http://127.0.0.1:4173 to preview the site. The static website lives in `nova-arhistudio/dist` and needs no build step.

See [the website README](nova-arhistudio/README.md) for content editing notes, image credits, and current limitations. Project information and stock photography are demonstration content pending the studio's real portfolio.
