# Nova Arhistudio

A responsive architecture and interior design portfolio built with HTML, CSS, and JavaScript. No dependencies or build step are needed.

## Preview

From this directory, run `node serve.mjs` and open http://127.0.0.1:4173.

## Content

- `dist/index.html`: page content and project brief dialog.
- `dist/styles.css`: responsive layout and visual design.
- `dist/app.js`: sample projects, filters, project dialogs, mobile navigation, and downloadable enquiry briefs.
- `dist/assets/`: locally stored photography.

Project names, dates, and descriptions are demonstration content, not verified Nova Arhistudio projects. Replace them and the stock photos before public launch. The enquiry dialog downloads a text brief locally; it does not send email or store personal information on a server.
